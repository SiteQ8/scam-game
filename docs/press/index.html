About the game

Every card is a realistic message on a phone screen. Players swipe left for scam and right for legit, and a debrief then highlights the exact words that gave it away, with a lesson for next time.

The game has a daily case shared by everyone, a journey of eight chapters, six themed card packs, a 60 second rush, a flag hunt, a party mode for one phone and an offline checker for messages players actually receive. Levels, badges, a daily streak, a tip each day, a family mode with larger text and a certificate for the whole journey keep players coming back. Calls are voiced and every example is fictional.
